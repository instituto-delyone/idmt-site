MEMORIA IMEDIATA — AIGAR MEMORY LAB

Coloque aqui arquivos .txt UTF-8 que precisam ser descobertos e carregados
durante a inicialização do Memory Lab. Se qualquer arquivo .txt falhar ao
carregar, o estado da camada será parcial/erro e os detalhes aparecerão no
diagnóstico. Esta pasta é uma camada de contexto recuperável, não um mecanismo
de treinamento dos parâmetros do modelo.
