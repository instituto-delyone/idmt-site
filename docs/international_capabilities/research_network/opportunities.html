Encontre onde sua pesquisa pode acontecer.

O IDMT organiza caminhos para fontes oficiais de pesquisa, inovação e financiamento. Use os portais para pesquisar oportunidades e, quando encontrar algo compatível, registre seu interesse na Research Network.

Em português simples: financiamento é o recurso disponibilizado para realizar uma pesquisa ou desenvolver um projeto. Grant é uma modalidade de financiamento. Eligibility significa os requisitos para poder participar.
