# Manual Interativo de Antibioticoterapia — IDMT

Estrutura inicial do projeto. A arquitetura visual, o `index.html`, a interatividade e o conteúdo clínico serão definidos após a análise das três imagens de referência enviadas pelo Instituto.

## Estrutura

- `index.html` — a criar após análise das referências visuais.
- `assets/` — imagens, ícones e outros recursos próprios do manual.

## Princípio editorial

Conteúdo clínico deverá ter fonte rastreável, indicação/contexto explícitos e revisão antes de ser apresentado como orientação operacional. Não preencher lacunas com suposições.
