CSI · Linguagem · Medicina · Algoritmos

Por que o CSI é tão importante?

O CSI é uma biblioteca de termos usados em várias línguas diferentes para descrever os mesmos procedimentos e técnicas usadas na medicina, uma profissão na qual não há barreiras linguísticas. Ou seja, é uma plataforma que traduz não só as doenças, mas o ofício para todas as línguas e para os algoritmos.
